# wayfarer-s2cells

Resources for planning Niantic Wayfarer submissions using **S2 cell** boundaries (especially Level 17 for Pokémon GO).

- [S2-Cells.md](./S2-Cells.md) — overview of S2 levels and gameplay rules
- [extension/](./extension/) — **Chrome extension** that overlays the S2 grid on the official Wayfarer map

## Quick start

Load the unpacked extension from [`extension/`](./extension/) — see [extension/README.md](./extension/README.md).
